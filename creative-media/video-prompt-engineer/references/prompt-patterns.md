# Prompt Patterns Reference

## Templates by Genre

### Cinematic Drama
[Character] [action + speed] [environment + time]. [Shot size], [camera move]. [Lighting]. Shot on [film stock], [grade].

Example: A grieving father sits alone at a kitchen table at 3am. Medium close-up, static. Harsh overhead light. Shot on 16mm, cold desaturated tones.

### Action
[Character] [dynamic verb] [environment]. [Fast shot], [aggressive camera]. [Energy]. [Aesthetic].

Example: A soldier sprints through a burning building. Low angle wide, shaky handheld. Smoke and debris. High contrast, orange and grey grade.

### Nature / Landscape
[Subject] in [environment] at [time]. [Camera move], [shot size]. [Weather/light]. [Aesthetic].

Example: Ancient redwood trees in morning fog. Slow aerial descent, ultra wide. Golden shafts of light. Shot on IMAX, rich greens, film grain.

### Sci-Fi
[Subject] [action] in [futuristic setting]. [Shot type], [camera]. [Lighting]. [Visual style].

Example: A humanoid robot walks a neon-lit rain-soaked alley. Medium tracking, low angle. Neon blue and purple. Blade Runner aesthetic, heavy haze.

## Camera Movement Vocabulary

| Movement | Effect |
|---|---|
| Dolly in | Builds intimacy or tension |
| Dolly out | Distance, loneliness |
| Pan left/right | Reveals environment |
| Tilt up/down | Scale, power |
| Tracking | Follows movement |
| Handheld | Energy, urgency, realism |
| Steadicam | Smooth follow |
| Aerial descend | Grandeur, arrival |
| Orbit/arc | 3D space, hero moment |
| Static | Weight, contemplation |

## Shot Sizes

| Shot | Framing |
|---|---|
| Extreme wide | Landscape, subject tiny |
| Wide | Full subject + context |
| Medium wide | Knees up |
| Medium | Waist up |
| Medium close | Chest up |
| Close-up | Head and shoulders |
| Extreme close-up | Eyes, hands, detail |

## Aesthetic Style References

| Style | Key Visual Elements |
|---|---|
| Deakins-esque | Naturalistic light, muted palette |
| Neon Noir | Neon, rain, deep shadows |
| Terrence Malick | Natural light, wide angles, poetic |
| Kubrick | Perfect symmetry, cold light |
| Wes Anderson | Flat pastels, centered framing |
| Wong Kar-wai | Warm reds/greens, blur |
| Grindhouse | Film damage, grain |
| Social Realism | Handheld, natural light, raw |
